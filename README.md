# 🛍️ Eletro Kurumin - Loja Virtual de Componentes Eletrónicos

Interface de comércio eletrônico **clean, moderna e intuitiva**, desenvolvida especialmente para os clientes da **Eletro Kurumin** comprarem componentes eletrônicos, placas didáticas, módulos e sensores com agilidade e total segurança.

---

## 🎯 Foco na Experiência do Cliente (Sem Telas Internas de Receita)
O cliente tem acesso exclusivo a uma **loja virtual rápida e profissional**:
- ✅ **Catálogo Visual de Peças:** busca em tempo real e filtros por categoria (*Microcontroladores, Sensores, Circuitos Integrados, Passivos, etc.*).
- ✅ **Especificações Técnicas:** tensão de operação, encapsulamento, pinagem e aplicações recomendadas.
- ✅ **Disponibilidade Imediata:** status em tempo real (*"Em Estoque"*, *"Últimas Unidades"* ou *"Indisponível"*).
- ✅ **Carrinho Interativo:** barra de progresso para Frete Grátis, ajuste rápido de quantidades e cálculo de desconto de 5% no Pix.
- ✅ **Checkout Descomplicado:** escolha de forma de pagamento (Pix, Cartão de Crédito ou Boleto) com geração automática de chave Pix e botão para enviar o pedido diretamente para o **WhatsApp da Loja**.
- 🔒 **Privacidade da Empresa:** Métricas internas, custos, receita total e movimentações de auditoria permanecem ocultas dos clientes.

---

## 🚀 Como Abrir e Testar a Loja

### Opção 1: Via Servidor Node.js (Recomendado)
1. No terminal, execute:
   ```bash
   npm start
   ```
2. Abra no navegador:
   👉 **http://localhost:3000**

### Opção 2: Abertura Direta
- Basta dar um duplo clique no arquivo [`index.html`](file:///c:/Users/mf.andrade/Desktop/eleto_kurumin/index.html) no Windows Explorer. O sistema funciona automaticamente com persistência no navegador.

---

## 🛠️ Tecnologias
- **Frontend:** HTML5 Semântico, CSS3 Moderno (Clean UI / Minimalista) e JavaScript ES6+
- **Backend:** Node.js com Express 5
- **Persistência:** Banco de Dados Relacional MySQL com dedução e atualização automática de estoque.
